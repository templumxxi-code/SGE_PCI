🚀 COMO USAR

1. Aplicar a Migration:
   cd "Sistema 1/SMP PCI"
   psql -U postgres -d smp_pci -f database/migrations/0003_create_planejar_phase.sql

2. Iniciar o servidor:
   npm start
   # Ou para desenvolvimento:
   npm run dev

3. Acessar a interface:
   http://localhost:3000

4. Login com credenciais de teste:
   - Admin: admin@pci.rn.gov.br / admin123
   - Setor: setor@pci.rn.gov.br / setor123

5. Navegar para um processo e preencher a fase Planejar
